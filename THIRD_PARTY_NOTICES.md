# Asset and font provenance

The initial designs and SVG assets were supplied through the user's four FDS Figma libraries. Original file keys and node references are retained in figma/libraries.json, figma/icon-inventory.json, and figma/coverage.md.

The Iconography library describes its default icon set as Feather Icons by Cole Bemis, with 16px and 32px adaptations by Thomas Pernkopf. Preserve this attribution and the applicable upstream notices when expanding or distributing the icon package.

The docs app bundles Inter through @fontsource/inter; its package includes the font's license and metadata. The React Native package uses system fonts and does not redistribute SF Pro font files.

This setup does not assign a new license to the source Figma libraries or declare the entire repository open source.
